# Privacy policy

BurnerPad's privacy policy is published at **https://zaegan.github.io/BurnerPad/privacy.html** (the address the app links to from
its settings).

It is no longer kept in this repository: the source is `BurnerPad/privacy.html` in
[Zaegan/Zaegan.github.io](https://github.com/Zaegan/Zaegan.github.io), which holds the policies for all of Zaegan's
apps. Edit it there. GitHub Pages is off for this repository on purpose; turning it back on would make this
repository's site take over that address.
